Basler Lens C11T-08-110-VI#

High-performance single-sided telecentric lens with a F6.6 fixed aperture and a magnification of 0.8.

Key Features#

  • Fits all Basler cameras with a sensor size of up to 1.1"
  • Metal housing
  • C-Mount
  • Variable iris
  • Excellent value for money

Info
