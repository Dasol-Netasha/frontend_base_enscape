# Core Web Frontend

Vue 3 + Vite 기반 프론트엔드 시작점입니다.

포함된 스택:

- Vue 3
- Vite
- Vue Router
- Pinia
- Tailwind CSS v4
- Axios
- ECharts

기본 화면 구성:

- 대시보드
- 이미지품질이상
- 장비구동이상
- 통합 이상
- 데이터

실행:

```bash
npm install
npm run dev
```

환경 변수:

- `VITE_API_BASE_URL`: 백엔드 API 기본 주소, 기본값은 `http://localhost:8000/api/v1`
